# umap

`umap` is a planned, allocation-conscious Go implementation of Uniform
Manifold Approximation and Projection (UMAP).

The project is currently in its contract and measurement phase. The proposed
v1 Go API, the Python compatibility target, and numerical guarantees are
specified in [the v1 API and compatibility contract](docs/v1-contract.md).

No implementation is published yet. The contract is intentionally being
reviewed before implementation choices make compatibility expensive.
